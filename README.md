# 재현 패키지: 같은 커피 취향을 다르게 말하면 AI의 원두 추천도 달라질까?

## 폴더 구성

| 위치 | 내용 |
|---|---|
| `논문.docx` | 이 논문 |
| `raw/` | 원자료. 요청 30개마다 보낸 문장과 AI 응답 원문 전체 (`01_A.txt` ~ `30_C.txt`). 앞의 숫자는 요청 번호, 뒤의 알파벳은 문장 종류(A, B, C) |
| `screenshots/` | 원자료 보충. 요청 30개의 화면 캡처 (`01_A.png` ~ `30_C.png`) |
| `data.csv` | 원자료를 원두 단위(30 × 5 = 150줄)로 정리한 표 |
| `scripts/build_data.py` | `raw/`의 응답에서 `data.csv`를 만들고, 정리한 값이 응답 제목 줄에 실제로 있는지 검사한다 |
| `scripts/analyze.py` | 같은 원두의 개수를 세고 사전에 정한 기준(0.5개)으로 판정한다. 주 규칙과 보조 규칙 두 가지를 계산한다 |
| `scripts/make_figures.py` | 그림 1과 추천 빈도표를 만든다 (matplotlib 필요. 확인 기준에는 들어가지 않는다) |
| `results/` | 계산 결과 (`summary.csv`, `freq.csv`, `fig1_overlap.png`) |
| `pilot/` | 시험 실행 2회의 원자료. 본 데이터 30건에 포함하지 않는다 |
| `문서/` | 1~3단계 문서 (가설, 논거, 설계와 설계 변경 기록) |

## 재현·통과 확인 4가지

**1. 어디서 확인하나**
ZIP을 새 폴더에 풀고, 터미널(Windows는 명령 프롬프트나 PowerShell)을 열어 `scripts` 폴더가 보이는 그 폴더 안으로 이동한다. Python 3이 필요하다. (Windows에서 `python3`이 안 되면 `python`으로 쓴다.)

**2. 무엇을 하나 (3단계)**
1. `python3 -I scripts/build_data.py` 를 실행한다. (`-I`는 폴더 안의 다른 파일을 끌어 쓰지 않고 실행하라는 뜻이다.)
2. `python3 -I scripts/analyze.py` 를 실행한다.
3. `results/summary.csv`를 열어 화면에 나온 숫자와 같은지 본다.

**3. 무엇이 보이면 통과**
- 1단계 실행 후 화면에 `요청 수 30 문장별 {'A': 10, 'B': 10, 'C': 10} / 줄 수 150 / 원문 파일 수 30` 과 `검사에서 걸린 것: 0` 이 나온다.
- 2단계 실행 후 `=== 주 규칙 ===` 아래에 다음 세 줄이 나오고 마지막에 `가설 판정: 세 쌍 모두 비슷하다 -> 가설 지지` 가 나온다.
  - `A-B: 쌍 100개, 표현 간 평균 3.96, 기준선 4.00, 차이 +0.04 -> 비슷하다`
  - `A-C: 쌍 100개, 표현 간 평균 4.02, 기준선 4.16, 차이 +0.14 -> 비슷하다`
  - `B-C: 쌍 100개, 표현 간 평균 3.85, 기준선 3.96, 차이 +0.11 -> 비슷하다`
- `=== 보조 규칙(이름이 완전히 같을 때만) ===` 아래에서도 세 쌍 모두 `비슷하다`가 나온다 (A-C의 차이는 +0.40).

**4. 안 될 때**
- `python3: command not found` 또는 `'python3'은(는) 인식되지 않습니다`: Python 3을 설치하거나 `python`으로 바꿔 실행한다.
- `No such file or directory`나 `FileNotFoundError`: `scripts`, `raw`, `data.csv`가 한 폴더에 같이 있는 곳에서 실행하고 있는지 확인한다. ZIP을 다시 풀어 본다.
- 숫자가 위와 다르거나 `검사에서 걸린 것`이 0이 아니다: `data.csv`나 `raw/` 안의 파일을 고치지 않았는지 확인하고, ZIP을 새로 풀어 1단계부터 다시 한다.
- 그림을 만드는 `make_figures.py`는 `pip install matplotlib` 후에 실행한다. 한글이 네모로 보이면 글꼴 문제이고, 숫자 확인에는 영향이 없다.

## 분류 규칙과 한계

같은 원두를 판단하는 규칙(생산국, 세부 지역, 품종, 가공 방식 네 칸 비교와 예외)은 논문 2.3과 `문서/3단계_설계.md` 4번에 있다. 이 규칙은 30회를 모두 모은 뒤, 겹침을 계산하기 전에 확정했고 그 경위는 설계 변경 기록에 적었다. 원두 150개를 네 칸으로 정리하는 일은 AI가 했고 작성자가 150줄을 전부 다시 확인하지는 않았다.
